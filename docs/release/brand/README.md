# Garajo brand

The **Livery** mark: a slanted motorsport G with chamfered corners and a cyan
headlight, set against racing stripes. It replaced the earlier round G, which
was too close in shape to Google's G.

| File | Use |
|---|---|
| `garajo_icon_1024.png` | App icon on dark (also `assets/icon/app_icon.png`) |
| `garajo_icon_light_1024.png` | App icon on white, e.g. press and partner pages |
| `garajo_mark_transparent_1024.png` | The G alone, transparent, for overlays and print |
| `logo_concepts.png` | The three concepts considered (Gauge, Livery, Road) |

Colours: orange gradient `#FF8A4C` → `#FF4A2A`, cyan `#2CE5FF`,
background `#0B0E14`.
